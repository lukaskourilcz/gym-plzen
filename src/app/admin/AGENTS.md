# Administration design

Apply the Apple Design skill only within the administration. Reference:
https://github.com/emilkowalski/skills/blob/main/skills/apple-design/SKILL.md

Use clear grouped navigation, platform typography, instant press feedback,
accessible native controls and reduced motion. Reuse the documented semantic
colours and UI primitives. Scope styles to `.admin-shell`; public pages retain
their design. Document new reusable patterns in `docs/DESIGN_SYSTEM.md` and the
protected component gallery. Never test against live reservations or providers.
